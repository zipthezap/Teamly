# App Directory

This directory contains the frontend application structure for Teamly.

## Structure

- **pages/** - Application pages and routes
  - Contains page components that represent different views/routes in the application
  
- **ui/** - Reusable UI components
  - Contains shared components like buttons, forms, cards, etc.

## Getting Started

This structure is ready for integration with a frontend framework like React, Next.js, Vue, or similar.

### Example Usage

```javascript
// Import a page
import HomePage from './pages/index.js';

// Import a UI component
import Button from './ui/Button.js';
```

## Future Development

This structure can be expanded to include:
- `layouts/` - Page layout components
- `hooks/` - Custom React hooks
- `utils/` - Frontend utility functions
- `styles/` - Global styles and themes
- `services/` - API client services
- `store/` - State management
